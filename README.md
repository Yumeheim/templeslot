## 架空寺

常用漢字2136文字から寺院の名前をランダムに決めます。
面白い寺の名前を考えるというネタツイの一環です。ぜひ投稿して、あなただけの面白寺を知らせて下さい。

- 自動輪転
  - オートで回し、停止します。
  - 1秒回転し、1.5秒停止します。ドパガキ向けにしております。ご了承ください。

- 御朱印帳(お気に入り)
  - ブラウザ上に保存されます。
  - ブラウザのCookieを消すと履歴が消えます。
  - 個別に布教(投稿)、廃仏(削除)が出来ます。
 
- 布教(X投稿)
  - Xに投稿できます。ハッシュタグは #架空寺 です。

- 注意事項
  - 命名した名前によっていかなる損害・被害が出ても、当方は責任を負いかねます。
  - 性質上、実在する寺院の名前や、不適切な寺院の名前も生成されます。SNSへの投稿は自己責任で行ってください。
  - 他、何かあればXアカウント(@yumeheim)にお知らせください。
